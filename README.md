## Установка и запуск

Нужны Python 3.12+, актуальный Chrome или Firefox и доступ к сайту.
Все команды ниже выполняются в Bash из папки проекта.

```bash
# Создать отдельное окружение Python в папке .venv.
python3 -m venv .venv

# Установить в него зависимости из requirements.txt.
.venv/bin/python -m pip install -r requirements.txt

# Запустить все тесты в Chrome без видимого окна.
.venv/bin/python -m pytest
```

Активировать окружение не нужно: в командах указан путь к его Python.
В Windows используйте `.venv\Scripts\python.exe`.
Selenium Manager подбирает WebDriver автоматически; при первом скачивании
драйвера нужен доступ к сети.

```bash
# Запустить тесты в Firefox.
.venv/bin/python -m pytest --browser=firefox

# Показывать окно браузера.
.venv/bin/python -m pytest --headed

# Увеличить ожидание элементов до 30 секунд.
.venv/bin/python -m pytest --timeout=30

# Запустить только календарь; -v выводит названия тестов.
.venv/bin/python -m pytest tests/test_calendar.py -v

# Выбрать только тесты с меткой negative.
.venv/bin/python -m pytest -m negative

# Указать путь к установленному драйверу подходящей версии.
.venv/bin/python -m pytest --driver-path=/absolute/path/to/chromedriver

# Указать бинарный файл Firefox, если автоматический поиск находит оболочку.
.venv/bin/python -m pytest --browser=firefox --browser-binary=/absolute/path/to/firefox

# Отключить sandbox Chrome, если среда не поддерживает его запуск.
.venv/bin/python -m pytest --no-sandbox

# Сохранить результаты дополнительно в JUnit XML.
.venv/bin/python -m pytest --junitxml=artifacts/junit.xml
```

По умолчанию ожидание элементов — 20 секунд, загрузки страницы — 60 секунд.
Базовый адрес задаётся через `--base-url=https://practice-automation.com/`;
тесты рассчитаны на структуру и поведение этого сайта.

Для Firefox из Snap укажите браузер и драйвер напрямую:

```bash
# --browser-binary задаёт браузер, --driver-path — совместимый geckodriver.
.venv/bin/python -m pytest --browser=firefox --browser-binary=/snap/firefox/current/usr/lib/firefox/firefox --driver-path=/snap/firefox/current/usr/lib/firefox/geckodriver
```

## Отчёты Allure

Результаты записываются в `artifacts/allure-results/`. Перед каждым запуском
эта папка очищается. Для отдельного прогона укажите другой путь:
`--alluredir=artifacts/another-run`.

В отчёте есть названия тестов и шаги выполнения. При падении теста или его
подготовки прикладываются скриншот, URL и HTML страницы. Если браузер не удалось
создать, скриншота не будет. Версии среды сохраняются в `environment.properties`.

Для генерации HTML используется Allure Report 3.22.1. Проверены Node.js 24.22.1
и pnpm 11.25.0. Java не требуется; сами Python-тесты запускаются без Node.js.

```bash
# Установить генератор отчёта по зафиксированному pnpm-lock.yaml.
pnpm install --frozen-lockfile

# Собрать однофайловый HTML-отчёт в artifacts/allure-report/.
pnpm run report
```

При сборке удаляются метки компьютера и процесса (`host`, `thread`), атрибут
`hostname` из JUnit XML и скрипты внешней аналитики из готового HTML.

Если уже установлен Allure Report 2, можно использовать его:

```bash
# Удалить служебные метаданные из результатов перед сборкой Allure 2.
python3 tools/build_report.py --sanitize-only

# Собрать отчёт; -o задаёт папку, --clean очищает предыдущую сборку.
allure generate artifacts/allure-results -o artifacts/allure-report-v2 --clean

# Запустить локальный просмотр отчёта.
allure open artifacts/allure-report-v2
```

## Структура проекта

```text
pages/               # Page Object: общие действия и страницы упражнений
tests/               # Сценарии, фикстуры браузеров и вложения Allure
verification/        # Сохранённые результаты полного прогона
tools/               # Очистка метаданных и сборка отчёта
requirements.txt     # Версии зависимостей Python
pyproject.toml       # Настройки Pytest
package.json         # Команда сборки отчёта
pnpm-lock.yaml       # Зависимости генератора Allure
```

Page Object описывают действия с интерфейсом, тесты проверяют результат.
Используются CSS-селекторы, относительные XPath и явные ожидания без
`time.sleep`. Каждый тест получает новый профиль браузера без расширений
и блокировщиков рекламы. Автоматических перезапусков упавших тестов нет.

Перед каждым сценарием открывается соответствующая страница в новом браузере:
`/calendars/`, `/modals/`, `/ads/` или `/form-fields/`.

| ADS-P07 | Позитивный | Повторить при ширине окна 768 px | Аналогичная проверка при более широком окне |

времени срабатывания. В ADS-N03 окно наблюдения — 6 секунд.

### Form Fields

| ID | Тип | Действия | Ожидаемый результат |
|---|---|---|---|
| FORM-P01 | Позитивный | Получить `li` списка Automation tools через `find_elements`; прочитать `.text`; объединить через `, `; ввести в Message | Список непустой; Message содержит актуальные названия в исходном порядке через запятую |

Этот сценарий выполняет отдельный пункт задания про Message. Список читается
со страницы, поле заполняется через `send_keys`; названия инструментов в коде
не заданы.
